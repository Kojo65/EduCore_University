# EduCore University website

This Vite and React app keeps the supplied page designs intact and makes them available as local routes.

## Run in VS Code

1. Open this folder in VS Code.
2. Run `npm install` in the integrated terminal if dependencies are not installed.
3. Run `npm run dev` and open the local URL Vite prints.

## Pages

- `/` — Public university homepage
- `/about` — University history and colleges
- `/apply` — Sign up and admissions
- `/crest` — Crest and wordmark
- `/dashboard` — Student learning dashboard
- `/records` — Student records, exams, and digital library
- `/designs` — Gallery of the supplied page designs and image assets

The original page HTML and screenshots are copied into `public/reference-pages`. Campus, student portrait, and wordmark assets are in `public/supplied-assets`.

The `educore_portal` folder contains a design guide but no page HTML or screenshot, so there was no separate portal screen to add. The dashboard and records screens have their own supplied HTML and are included above.
