# Pages

Route-level screens live here, grouped by feature. Each page assembles reusable UI from `src/components`.

- `auth/`: admissions and applicant access
- `gallery/`: supplied design gallery
- `home/`: public university homepage
- `portal/`: student records, CBT, and digital library

Keep route selection in `src/DesignApp.jsx`. Put reusable feature UI in the matching `src/components` folder.
