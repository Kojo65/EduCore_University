CS304 Core: Russell & Norvig (4th Edition) • Chapter 3

3.4 Uninformed Search Strategies vs. Heuristic Search

A heuristic function, denoted h(n), is an estimated cost of the cheapest path from the state at node n to a goal state. If a heuristic satisfies h(n) ≤ c(n, a, n′) + h(n′) for every node n and successor n′ generated by an action a, it is deemed monotonic or consistent.

Algorithmic Lemma 3.2: A* Optimality Proof

When applied to a graph search problem where all action costs are strictly greater than zero, tree-search A* is optimal if the heuristic is admissible; graph-search A* is optimal if the heuristic is consistent.

In typical heuristic search formulations within real-time robotics and game trees, strict monotonicity prevents the necessity of reopening nodes in the closed set, substantially reducing computational complexity bounds from exponential to sub-polynomial spaces.
